# Artificial Intelligence for the Future of Computer Networking

## Overview

This project explores how Artificial Intelligence (AI) can improve the performance, security, and reliability of modern computer networks.

The research focuses on AI applications such as traffic prediction, intelligent routing, anomaly detection, and network resource allocation.

## Research Poster

![AI for the Future of Computer Networking](poster.png)

## Key Topics

- AI-based network traffic prediction
- Intelligent routing
- Network anomaly detection
- Resource allocation and congestion management
- Proposed AI-enabled network architecture
- Network performance evaluation
- Benefits, limitations, and future impact

## Proposed Architecture

The proposed architecture includes end devices, access points and switches, routers and network links, network monitoring, an AI-assisted controller, policy validation, and network adjustment.
